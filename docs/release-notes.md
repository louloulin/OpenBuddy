# 更新说明

> 本文描述当前预览分支的能力集合。当前构建未签名、未公证；功能是否真的可用以 [功能状态总表](FEATURE-STATUS.md) 为准，历史版本的详细说明见 [CHANGELOG.md](../CHANGELOG.md)。

## 1.0.0（当前）

首个公开预览版：WorkBuddy 风格界面 + Pi 执行引擎，本地优先。

### 核心

- 多模型服务商与本地模型；流式对话、工具审批、会话分支/重试/压缩。
- 项目（工作区 + 项目说明）、工作台与产物预览、检查点与还原。
- 专家与团队：专家绑定、子会话逐成员绑定、WorkBuddy 专家包导入（本地/https）。
- 技能与指令：市场安装、版本展示、批量启停、ZIP 导出；能力包整体/逐项开关与回退。
- 办公产物：`ob_docx` / `ob_xlsx` / `ob_pptx` 生成真实 OOXML，走权限门、检查点与产物刷新。
- 自动化：日/周/月/小时与文件触发、修订号、失败重试、运行记录。
- 连接器：MCP 管理与 OAuth 授权尝试（ID/到期/取消）。

### 数据与可靠性

- 数据文件带 `schemaVersion` 与顺序迁移；启动/迁移前/恢复前自动快照（保留 3 份）；损坏文件自愈或隔离。
- 全量导出/恢复（密钥不随包迁移）；会话 JSONL 导入导出。
- 应用级错误边界；主进程异常、渲染崩溃与加载失败统一记录；日志按日/大小轮转、7 天保留、写盘前脱敏。

### 更新与分发

- 「关于」页检查更新：读取发布清单（仅 HTTPS），显示版本、通道、更新说明与下载页；不静默安装。
- 离线依赖门禁、CycloneDX SBOM、可复现构建检查；CI 提供 Linux 验证 job。

### 界面与可访问性

- Grok Bot 视觉层：暖纸画布、发丝线、浅灰选中、悬浮 Composer。
- 键盘全链路与弹层焦点陷阱；6 个界面无障碍自动审计 0 问题。
- 对话/首页/设置/暗色两屏对比度 0 处低于 WCAG 4.5:1（大字号 3:1）。
- 1024×768 与 125% 缩放无横向溢出。
- 界面语言：简体中文 / English（设置页、侧栏、Composer 与首页文案），选择本地持久化。

### 移动端

- H5 界面 17 屏 × 亮/暗共 34 次回归通过；手机审批、通知与弱网路径可用。

### 已知限制

- macOS/Windows 安装包未签名、未公证；不支持自动安装更新。
- English 仅覆盖设置页与壳层，业务面板仍为中文。
- 未做系统读屏（VoiceOver/NVDA）实机走查。
- Linux 只跑验证，不产出安装包；漏洞库审计（`pnpm audit`/OSV）需联网与 CI。
