# 隐私说明

更新日期：2026-11-20

OpenBuddy 是本地优先的桌面应用——这也是「Buddy 真正属于你」的前提。下面说明数据在哪里、什么时候会离开你的设备，以及你可以怎么控制。产品主张见 [让每个人都能拥有自己的 Buddy](VISION.md)。

## 1. 默认本地的数据

- 会话、项目、自动化、产物、检查点、快照与设置都保存在本机应用数据目录。
- 模型服务商、MCP 与 Pi 的配置同样在本机。
- 应用没有内置遥测上传；诊断报告只在本机生成，需要你手动复制或保存。

## 2. 会发往模型服务商的内容

当你发送消息或运行自动化时，以下内容会发给你配置的模型服务商：

- 当前会话的消息与工具结果（用于继续对话）；
- 系统提示词中由应用提供的项目说明、技能/指令与专家人设；
- 你选择附带的文件内容（文本内联，较大文件只传路径给本地工具）。

使用的是你自己填写的 Base URL 与 API Key；数据如何存储与训练由该服务商的政策决定。使用本地模型时，请求不会离开本机。

## 3. 密钥

- API Key 通过 Electron `safeStorage` 加密后保存在 `credentials.enc.json`，依赖系统钥匙串。
- 密钥不进入日志、诊断报告或「导出全部数据」。
- 换机器后需要重新输入，因为加密与原钥匙串绑定。

## 4. 日志与诊断

- 主进程日志写入 `<数据目录>/logs/openbuddy-YYYY-MM-DD.log`，按日/大小轮转，保留 7 天。
- 写盘前会脱敏：`sk-…`/`token-…` 形态密钥、`Bearer`、邮箱、`/Users|/home|…` 等绝对路径。
- 诊断报告同样在本地脱敏；「让模型写摘要」是唯一会把当前会话交给模型的诊断选项，且需你勾选。

## 5. 更新检查

- 仅在你点击「检查更新」或配置了更新源时请求发布清单。
- 清单与下载地址只接受 HTTPS（本机回环调试除外），拒绝 URL 内嵌凭据。
- 应用不会静默下载安装包或替换自身。

## 6. 外部链接

「关于」「帮助与反馈」中的文档链接、更新下载页会在系统浏览器中打开；打开后适用对应网站的政策。

## 7. 删除数据

- 单个会话：侧栏右键 →「删除」。
- 全部数据：关闭应用后删除应用数据目录；或在「数据管理」里清理本地缓存（只影响列表显示）。
- 自动化运行记录可在自动化页归档或删除。

## 8. 联系方式

问题与隐私相关反馈：设置 →「帮助与反馈」→「生成诊断报告」，附上复现步骤后手动发送给维护者。
