# OpenBuddy 用户手册

OpenBuddy 是一个本地优先的桌面 AI 工作台：界面是 WorkBuddy 风格，执行引擎是 Pi（`@earendil-works/pi-coding-agent`）。任务在你自己机器上运行，会话、项目与产物都保存在本机；只有模型请求会发往你配置的模型服务商。

> 目标：新用户 15 分钟内完成第一个任务。按下面的顺序走一遍即可。

## 1. 安装与首次启动

- 安装包：从发布页下载 macOS（`.dmg`）或 Windows（`.exe`）安装包。当前构建未签名，macOS 首次打开需右键 →「打开」。
- 从源码运行（开发者）：

```bash
pnpm install
pnpm dev:electron          # 开发模式
pnpm build:electron        # 构建渲染层 + 主进程
pnpm dist:electron         # 打包安装包（输出到 release/）
```

需要 Node 24 与 pnpm 10.29.3。

## 2. 配置模型（约 3 分钟）

1. 打开左下角「设置」→「模型」。
2. 新增服务商：填写名称、Base URL，并在「API Key」里粘贴密钥。
   - 密钥保存在系统钥匙串（Electron `safeStorage`），不会写进明文配置，也不会进入数据导出包。
3. 拉取或手动添加模型，并把一个模型设为默认。
4. 回到首页，输入框可用即表示配置成功。

本地模型（llama.cpp / 兼容 OpenAI 的本地服务）：设置 →「模型」→ 本地模型，填写 Base URL 与模型名。

## 3. 第一个任务

1. 侧栏点「新建任务」。
2. 输入一句具体的话，例如「把这段 JSON 整理成 CSV：…」或「读一下 README，列出三个风险点」。
3. 需要运行工具（读写文件、命令）时会弹出审批卡片：可以「允许本次」「本会话允许」或拒绝；「设置 → 安全中心」可以改默认策略与受保护路径。
4. 结果在对话里流式显示；用到的文件会出现在右侧工作台，可预览、编辑、还原或下载。

工作模式（输入框上方）：

- **做一做**：正常执行，可改文件。
- **想一想**：先给计划，不改文件；确认后再执行。
- **问一问**：只回答，不改文件。

## 4. 专家、技能与连接器

- 「专家·技能·连接器」里可以：
  - 使用内置/导入的专家（含团队），把专家绑定到当前任务；
  - 安装技能（支持从市场复制到本地 `skills/`，也可导入 ZIP）；
  - 管理 MCP 连接器，授权采用 OAuth 尝试：弹层里可复制尝试 ID、看到到期时间，关闭即取消。
- 导入 WorkBuddy 专家包：支持本地包与 https 链接；重复导入按内容摘要去重。

## 5. 自动化

- 「自动化」可以按日/周/月/小时运行任务，也可以监听文件变化触发。
- 每次保存会生成新的修订号；运行记录锁定当时的修订，失败记录可一键重试。
- 目标工作区不可用时会留下带原因的失败记录，而不是静默跳过。

## 6. 数据位置、备份与恢复

数据目录：应用数据目录下的 `pi/`（macOS 通常为 `~/Library/Application Support/OpenBuddy/pi`，Windows 为 `%APPDATA%/OpenBuddy/pi`）。

- 设置 →「数据管理」→「导出全部数据」：导出一个 JSON 包（设置、模型、项目、自动化、MCP、Pi 设置）。
- 「从数据包恢复」：恢复前会自动生成快照，恢复后重启应用生效。
- 自动快照：启动、迁移前、恢复前各一份，保留最近 3 份，可回滚。
- **密钥不随包迁移**：`credentials.enc.json` 与系统钥匙串绑定，换机器后请重新输入 API Key。
- 单个会话可用 ⋯ 菜单「导出为 JSONL」；导入会复制成新会话。

## 7. 快捷键

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 搜索任务 | Cmd+K | Ctrl+K |
| 新建任务 | Cmd+N | Ctrl+N |
| 打开设置 | Cmd+, | Ctrl+, |
| 发送消息 | Enter | Enter |
| 换行 | Shift+Enter | Shift+Enter |
| 复制最后一条回答 | Cmd+Shift+C | Ctrl+Shift+C |
| 全局快速输入 | 可自定义（设置 → 通用） | 同左 |

发送键可在 设置 → 通用 改为 Ctrl/Cmd+Enter。

## 8. 更新

设置 →「关于」→「检查更新」会读取发布清单，显示版本、更新说明与下载页。安装包需要手动安装；应用不会静默替换自身。未配置更新源时会明确提示，不会伪造结果。

## 9. 遇到问题

- 先看 [常见问题](faq.md)。
- 设置 →「帮助与反馈」→「生成诊断报告」：报告在本机生成并脱敏（不含 API Key 与绝对路径），可预览、复制或保存，不会自动上传。
- 更细的排查步骤见 [故障排查](troubleshooting.md)。
