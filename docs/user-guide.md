# OpenBuddy 用户手册

OpenBuddy 是一个本地优先的桌面 AI 工作台：界面是 WorkBuddy 风格，执行引擎是 Pi（`@earendil-works/pi-coding-agent`）。任务在你自己机器上运行，会话、项目与产物都保存在本机；只有模型请求会发往你配置的模型服务商。

我们希望你不只是「用一个工具」，而是**拥有一个自己的 Buddy**——它记得你、有自己的人设、能动手干活，也知道什么不能碰。产品主张见 [让每个人都能拥有自己的 Buddy](VISION.md)。

> 目标：新用户 15 分钟内完成第一个任务。按下面的顺序走一遍即可。
> 当前是未签名预览版；每项功能的真实可用性以 [功能状态总表](FEATURE-STATUS.md) 为准。

## 1. 安装与首次启动

- 安装包：从 [Releases](https://github.com/louloulin/OpenBuddy/releases) 获取 macOS（`.dmg`）或 Windows（`.exe`）审核产物。当前构建未签名，macOS 首次打开需右键 →「打开」；不提供 Linux 安装包。
- 从源码运行（开发者）：

```bash
pnpm install
pnpm dev:electron          # 开发模式
pnpm build:electron        # 构建渲染层 + 主进程
pnpm dist:electron         # 打包安装包（输出到 release/）
```

需要 Node 24 与 pnpm 10.29.3。

## 2. 配置模型（约 3 分钟）

1. 打开左下角「设置」→「模型」。
2. 新增服务商：填写名称、Base URL，并在「API Key」里粘贴密钥。
   - 密钥保存在系统钥匙串（Electron `safeStorage`），不会写进明文配置，也不会进入数据导出包。
3. 拉取或手动添加模型，并把一个模型设为默认。
4. 回到首页，输入框可用即表示配置成功。

本地模型（llama.cpp / 兼容 OpenAI 的本地服务）：设置 →「模型」→ 本地模型，填写 Base URL 与模型名。

## 3. 第一个任务

1. 侧栏点「新建任务」。
2. 输入一句具体的话，例如「把这段 JSON 整理成 CSV：…」或「读一下 README，列出三个风险点」。
3. 需要运行工具（读写文件、命令）时会弹出审批卡片：可以「允许本次」「本会话允许」或拒绝；「设置 → 安全中心」可以改默认策略与受保护路径。
4. 结果在对话里流式显示；用到的文件会出现在右侧工作台，可预览、编辑、还原或下载。

工作模式（输入框上方）：

- **做一做**：正常执行，可改文件。
- **想一想**：先给计划，不改文件；确认后再执行。
- **问一问**：只回答，不改文件。

## 4. 专家、技能与连接器

- 「专家·技能·连接器」里可以：
  - 使用内置/导入的专家（含团队），把专家绑定到当前任务；
  - 安装技能（支持从市场复制到本地 `skills/`，也可导入 ZIP）；
  - 管理 MCP 连接器，授权采用 OAuth 尝试：弹层里可复制尝试 ID、看到到期时间，关闭即取消。
- 导入 WorkBuddy 专家包：支持本地包与 https 链接；重复导入按内容摘要去重。

### 4.1 应用（以 UpUp 为例）

应用是带展示信息的 Pi 包（`package.json` 里有 `pi.app`）：有卡片、自带场景、可以整体启停，并能声明自己的工具策略。OpenBuddy 自己是内置的默认应用，永远排在第一位。

- **安装**：更多 → 应用 →「安装 UpUp」→ 检查并安装（等价 `pi install https://gitcode.com/lumosaigroup/upup.git`，需要网络和 Git）。其他方式：「专家·技能·连接器 → 扩展」里填本地目录（已克隆的仓库，离线可用）、`npm:` 包名或 git 地址。
- **切换与场景**：侧栏的应用切换器选择当前应用；首页标题和场景行跟着变，点场景会把 prompt 填进输入框，由你确认后发送。
- **更新与回滚**：应用页「检查更新」→ 卡片上「更新」；每次安装/更新都会记下版本和 Git commit，卡片上可以「回滚到上一版本」。
- **数据卡**：UpUp 的行情、估值、风险等工具结果在回答下方显示为数据卡，带来源、截至时间和数据新鲜度（live / delayed）。只有附带来源和截至时间的结果才会出卡。「生成报告」会把这些数据放进输入框，由模型写成 Markdown 文件。
- **投研专家**：专家里的「金融投研」分类有基本面分析师、风险分析师、投研研究员，绑定后只保留 UpUp 的只读数据和计算工具。
- **推荐卡**：你的问题更适合某个已安装的应用时，对话里会出现推荐卡，可以切换、试试它的场景，或点「不用了」（之后不再推荐它）。
- **长期未使用**：已启用但 14 天以上没用过的应用，会在应用页提示停用；停用后它的工具和技能不再进入新会话，随时可以重新打开。点「保留」后 14 天内不再提醒。
- **安全边界**：真实交易类工具（`place_trade_order` / `cancel_trade_order`，含 `upup_` 前缀的同名工具）始终被平台拒绝，规则、模式和「始终允许」都不能放行。
- **免责声明**：数据来自第三方数据源（如东方财富、腾讯财经），可能延迟或回落到备用来源，仅供研究参考，不构成投资建议。
- **许可**：UpUp 以 MIT 许可发布，由其作者维护；OpenBuddy 不随安装包分发 UpUp，安装时直接从上游仓库获取。

## 5. 自动化

- 「自动化」可以按日/周/月/小时运行任务，也可以监听文件变化触发。
- 工作空间可以留空：留空的任务在「默认空间」里运行；填了就在那个目录里运行。
- 每次保存会生成新的修订号；运行记录锁定当时的修订，失败记录可一键重试。
- 目标工作区不可用时会留下带原因的失败记录，而不是静默跳过。

## 6. 数据位置、备份与恢复

数据目录：应用数据目录下的 `pi/`（macOS 通常为 `~/Library/Application Support/OpenBuddy/pi`，Windows 为 `%APPDATA%/OpenBuddy/pi`）。

- 设置 →「数据管理」→「导出全部数据」：导出一个 JSON 包（设置、模型、项目、自动化、MCP、Pi 设置）。
- 「从数据包恢复」：恢复前会自动生成快照，恢复后重启应用生效。
- 自动快照：启动、迁移前、恢复前各一份，保留最近 3 份，可回滚。
- **密钥不随包迁移**：`credentials.enc.json` 与系统钥匙串绑定，换机器后请重新输入 API Key。
- 单个会话可用 ⋯ 菜单「导出为 JSONL」；导入会复制成新会话。

## 7. 快捷键

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 搜索任务 | Cmd+K | Ctrl+K |
| 新建任务 | Cmd+N | Ctrl+N |
| 打开设置 | Cmd+, | Ctrl+, |
| 发送消息 | Enter | Enter |
| 换行 | Shift+Enter | Shift+Enter |
| 复制最后一条回答 | Cmd+Shift+C | Ctrl+Shift+C |
| 全局快速输入 | 可自定义（设置 → 通用） | 同左 |

发送键可在 设置 → 通用 改为 Ctrl/Cmd+Enter。

## 8. 更新

设置 →「关于」→「检查更新」会读取发布清单，显示版本、更新说明与下载页。安装包需要手动安装；应用不会静默替换自身。未配置更新源时会明确提示，不会伪造结果。

## 9. 遇到问题

- 先看 [常见问题](faq.md)。
- 设置 →「帮助与反馈」→「生成诊断报告」：报告在本机生成并脱敏（不含 API Key 与绝对路径），可预览、复制或保存，不会自动上传。
- 更细的排查步骤见 [故障排查](troubleshooting.md)。

## 10. 把它变成你的 Buddy

前面几步里的能力可以组合成一个长期搭档：

- **记忆**：项目说明、检查点与快照让它跨会话记得你；单个会话也可以导出 JSONL 留档。
- **人格**：在「专家·技能·连接器」里绑定专家、编辑提示词，或直接导入 WorkBuddy 专家包。
- **手脚**：安装技能、添加 MCP 连接器，让它在授权范围内读写文件与调用工具。
- **自主**：把常用任务存成自动化，按时间或文件变化触发。
- **边界**：安全中心调整默认策略与受保护路径；每次工具调用都可以单独审批。
