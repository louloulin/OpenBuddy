# 常见问题（FAQ）

## OpenBuddy 里的「Buddy」是什么？

Buddy 是一个长期属于你的 AI 搭档，而不是一次性的聊天窗口。它由五部分组成：记忆（会话 / 项目 / 快照）、人格（专家 / 提示词）、手脚（技能 / MCP）、自主（自动化）和边界（审批 / 受保护路径）。详见 [产品主张](VISION.md)；每项能力的真实状态见 [功能状态总表](FEATURE-STATUS.md)。

## 有些菜单项为什么看不到？

界面会先询问当前宿主支持哪些命令（`host_capabilities`），只展示真的能用的入口。浏览器预览没有宿主能力，因此大部分入口会隐藏——这是预期行为，不是故障。细节见 [功能状态总表](FEATURE-STATUS.md)。

## 我的数据存在哪里？

全部在本机应用数据目录的 `pi/` 下：`openbuddy.json`（设置）、`providers.json`（模型）、`projects.json`、`automations.json`、`automation-records.json`、`mcp.json`、`pi-settings.json`、`sessions/`（Pi 会话）以及 `snapshots/`（快照）。数据文件带 `schemaVersion`，升级时按顺序迁移。

## API Key 会被上传或导出吗？

不会。密钥由系统钥匙串加密后保存在 `credentials.enc.json`，不会进入诊断报告、日志或「导出全部数据」。日志写盘前会脱敏 Key、Bearer、邮箱与绝对路径。

## 如何换模型或加一个本地模型？

设置 →「模型」。云端服务商填 Base URL + API Key 后拉取模型；本地模型在「本地模型」里填写 OpenAI 兼容的 Base URL 与模型名。默认模型在模型列表里设置。

## 断网还能用吗？

界面、历史会话、项目、产物与自动化记录都在本地，断网仍可浏览。模型请求需要网络；使用本地模型时全程离线。

## 为什么工具执行前要审批？

写文件、执行命令等会改变系统的操作默认需要确认。可以在弹层里「允许本次」「本会话允许」，或在 设置 → 安全中心 调整默认策略。`.env`、`.ssh`、`*.pem` 等受保护路径无论什么模式都会拒绝写入。

## 「想一想」和「做一做」有什么区别？

「想一想」只读：先给计划，不改文件；确认后再执行。「做一做」可以直接改文件；「问一问」只回答。

## 专家和技能是什么关系？

专家定义人设/模型/工具边界；技能是可复用的操作说明（`SKILL.md`），安装后出现在 `/` 菜单。团队包会把成员作为子会话运行，各自绑定自己的专家。

## 自动化为什么没有按预期运行？

检查三件事：任务是否为「启用」、工作区是否存在且已授权、下一次运行时间是否已生成。失败会在运行记录里留下原因，可直接点「重试」；每次保存都会 +1 修订号，旧运行不会被新编辑改写。

## 更新检查显示「未配置更新源」怎么办？

这是预期行为：未设置 `OPENBUDDY_UPDATE_FEED` 时应用不会猜测地址。配置发布清单后，「关于」页会显示新版本、更新说明与下载页；应用不会静默安装。

## 怎么备份或换电脑？

设置 →「数据管理」→「导出全部数据」，在新机器上「从数据包恢复」，重启后生效。API Key 需要重新输入（密钥与钥匙串绑定）。单个会话也可以导出 JSONL。

## 数据损坏了会怎样？

读取失败的 JSON 会先从最近一份包含它的快照恢复；没有可用快照时，损坏文件会被隔离为 `<file>.corrupt-<时间戳>`，应用用默认值继续启动。可在「数据管理」里回滚到任一快照。

## 支持哪些平台？

目前提供 macOS 与 Windows 安装包（未签名，仅内部审阅）。Linux 只在 CI 上跑验证，不产出安装包。手机端通过 Gateway 接入，需自行配置网关地址与令牌。

## 如何反馈问题？

设置 →「帮助与反馈」→「生成诊断报告」。报告在本机生成、脱敏，先预览再决定是否复制/保存；也可以在报告里附上复现步骤。
