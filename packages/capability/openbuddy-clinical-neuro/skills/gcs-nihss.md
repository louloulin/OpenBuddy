# GCS 与 NIHSS 评分要点

## GCS
总分 = E + V + M,范围 3-15。
* E(睁眼):4 自动 / 3 呼唤 / 2 刺痛 / 1 无
* V(语言):5 正确 / 4 错误 / 3 含糊 / 2 声叹 / 1 无
* M(运动):6 遵嘱 / 5 定位 / 4 躲避 / 3 屈曲 / 2 过伸 / 1 无

**注意**:插管患者 V 记 T;双眼肿胀 E 记 1c;总分报告建议写 E_V_M 分项而不是只写总分。

## NIHSS(11 项,总分 0-42)
关键项:
* 1a-1c 意识(0-9)
* 5/6 肢体肌力(0-16,左右各 8)
* 9 语言(0-3)
* 10 构音(0-2)

**陷阱**:
* 只能查协作患者,插管/镇静患者部分项目记无法评估
* 评分越高越重:0 正常,1-4 轻,5-15 中,16-20 中重,21+ 重
* 基线 NIHSS 与 24h NIHSS 变化用于溶栓效果评估
