# 神经系统鉴别诊断

## 使用场景
医生提供主诉、现病史、查体、影像/检验结果后,生成鉴别诊断列表。

## 推理流程

1. **定位病变**:根据症状和体征判断病变部位(大脑半球/基底节/脑干/小脑/脊髓/周围神经/神经肌肉接头/肌肉)
2. **定性病变**:血管性/感染性/肿瘤性/脱髓鞘/变性/代谢/中毒/外伤/功能性
3. **时间模式**:超急性(分钟-小时)/急性(小时-天)/亚急性(天-周)/慢性(月-年)/复发性-缓解性/进展性
4. **危急筛查**:颅内压增高征象、脑疝先兆、呼吸循环不稳、急性卒中时间窗、SAH 再出血风险
5. **生成列表**:按"危急 → 高概率 → 中概率 → 低概率但不可漏诊"排序

## 常见陷阱

* 后循环卒中早期可仅表现为眩晕/呕吐,易漏诊 → 结合 HINTS / NIHSS
* SAH CT 阴性不能排除 → 需腰穿或 CTA
* 低钠血症 + 头痛 = 考虑 SAH 后脑血管痉挛或脑性盐耗综合征
* 年轻女性 + 视神经炎 + 脊髓症状 = 考虑 NMOSD / MOGAD
* 快速进展性痴呆 + 肌阵挛 = 考虑 CJD
* 突发霹雳样头痛即使神志清楚也要排 SAH

## 关键量表联动
* 急性缺血性卒中 → NIHSS + ASPECTS
* 颅脑损伤 → GCS + Marshall CT
* 蛛网膜下腔出血 → Hunt-Hess + Fisher CT + mFisher
* 预后评估 → mRS
